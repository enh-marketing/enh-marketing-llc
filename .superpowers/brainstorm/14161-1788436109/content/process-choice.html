Section 04: How Forecasting Works

Six numbered steps. One to four happen before any budget is spent (confirm the goal, align the data, establish a range, build scenarios). Step five begins "Once the campaign starts". Step six adjusts as data arrives. Every step's subject is "we", so there is no client/agency handover to mark here, unlike AI Automation. Which treatment?

A. Pinned run with a start line

Reuses LaunchTrack from AI Automation: the section pins while six stage cards travel sideways, the nearest card lit, a progress rail underneath with a tick where the campaign goes live. Relabelled for this document ("Before the campaign", "Campaign starts", "Campaign live") and with the ENH/You pill dropped, since every step here is ours. Native swipe rail on phones. Zero new drawing code; one small change to make the actor pill optional.

B. Sticky counter

Reuses StageTimeline (Influencer Marketing) or StageLadder (LinkedIn Ads, AEO & GEO): a display-scale step number stays pinned on the left while the six steps scroll past on the right, with a meter reading progress. Vertical, so it reads well on phones without a fallback mode. Does not mark the campaign-start threshold, which is the one structural fact in this list.

C. One forecast, built step by step

New component. The six steps sit as a sticky list; one chart beside them accumulates as each step arrives: the goal line, aligned data points, the range, three scenario markers, the live line, then the range adjusting. The most content-specific drawing on the page, and no numbers anywhere. But it is the same mechanic as section 03 (scroll-driven drawing beside a list), so two adjacent sections would move the same way.

Recommendation: A. After section 03's vertical scrub, a horizontal pinned run changes the page's rhythm, and the start line is the one thing this list has that a plain sequence does not. C is the more original drawing; if you prefer it, I would then switch section 03 to option B (the sheet) so the two do not repeat each other.
