Campaign Intelligence: which hero visual?

Each sketch is built only from ideas the document states. No numbers appear anywhere. The real build will be an SVG in the hero's right-hand panel, animated with CSS or GSAP, gated behind reduced motion, exactly like the AI Automation agent graph.

A. The range, and the line inside it

A forecast band is drawn first. The live result line then draws itself inside the band and, near the end, steps outside it: the point an early alert fires. This is the document's whole argument in one picture: estimate a range, then watch whether the campaign stays within it.

B. One budget, divided

A single budget bar splits into the five named channels, and the split keeps rebalancing as scenarios change. Official channel marks from the existing ChannelIcon set sit beneath. This leads with Media Mix Planning and Scenario Planning rather than with monitoring.

C. Three scenarios, three ranges

Reduce, proposed and increase, each as a range that breathes wider or narrower as the assumptions beside it change. Quieter than A, and it carries the document's repeated point that a forecast is a range with stated assumptions, never a single number.

My recommendation is A. It shows pre-campaign forecasting, early alerts and forecast-versus-actual reporting in one mechanism, which is three of the six things the service covers. B would then become the Media Mix Planning section's own drawing, and C the Scenario Planning drawing, so none of the three ideas is lost.
